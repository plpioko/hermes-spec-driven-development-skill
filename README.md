# hermes-spec-driven-development-skill

A Hermes skill for facilitating spec-driven development (SDD) with coding agents. Hermes guides the workflow—from greenfield/brownfield assessment and project constitution through roadmap, feature specifications, implementation, regression testing, and phase review—while coordinating user-selected agents that can draft documents, assess code, write code, and run tests. It keeps the user in control of product decisions and verifies agent results against the repository and real test output.

The skill is based in part on DeepLearning.AI's "Spec-Driven Development with Coding Agents" course and companion repository.
